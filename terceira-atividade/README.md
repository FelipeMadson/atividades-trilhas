# Terceira atividade: Organizando Cubos

Exercício de CSS e Flexbox do curso Introdução ao Desenvolvimento Web: HTML, CSS e JavaScript.

## Como abrir

Abra `index.html` no navegador. Ele já carrega o arquivo `style.css` da mesma pasta.

## O que foi feito

O CSS organiza os oito cubos de acordo com a imagem do exercício:

1. Caixinhas na parte superior, com espaços iguais.
2. Coluna com as cores em ordem inversa, na parte inferior esquerda.
3. Coluna centralizada, com espaço entre as caixinhas.
4. Caixinhas centralizadas na horizontal e na vertical.
5. Caixinhas no canto inferior direito.
6. Segunda caixinha com o dobro da largura das outras.
7. Terceira caixinha branca.
8. Caixinhas maiores, distribuídas em duas linhas.

Foram usados `display: flex`, `flex-direction`, `justify-content`, `align-items`, `flex` e `flex-wrap`. Em telas menores, os cubos passam para duas ou uma coluna.
