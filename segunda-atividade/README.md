# Segunda atividade: Casa em Chamas

Jogo Herói das Chamas, feito somente com HTML para a atividade de Fundamentos da Web com HTML.

O objetivo é entrar na casa e encontrar a pessoa que precisa de ajuda. Cada página representa um espaço do mapa da atividade, e os links permitem ir de um lugar para outro.

## Como jogar

Abra o arquivo `index.html` desta pasta no navegador. Você começa na rua e escolhe por onde entrar. Continue clicando nos links para explorar os cômodos até concluir o resgate.

Não precisa instalar nada. O jogo usa apenas títulos, parágrafos, listas e links do HTML.
